# ⚡ DevGuard — AI Code Reviewer & Security Auditor

DevGuard is a full-stack, production-ready AI application designed to automate code auditing, security vulnerability checks, and code refactoring across multiple programming languages using Google's Gemini models.

🚀 **Live App Link:** [https://devguard-ai-reviewer.streamlit.app/](https://devguard-ai-reviewer.streamlit.app/)

---

## ✨ Features

* **Automated Code Auditing:** Detects syntax bugs, logical errors, and anti-patterns.
* **Security Inspection:** Identifies vulnerabilities (SQL injection risks, memory leaks, unsafe operations).
* **Code Optimization:** Recommends clean, refactored, and performant code snippets.
* **Multi-Language Support:** Python, C, C++, Java, JavaScript, TypeScript, Go, and more.
* **Interactive UI:** Supports direct code input as well as file uploads (`.py`, `.cpp`, `.js`, etc.).
* **Enterprise Security:** Built with strict environment variable isolation and cloud secrets management.
